# 游客照人像优化跨场景验证

- 基线：[当前产品 PRD](../../PRD.md)
- 依赖：无

## 背景与目标

单人游客照的自然美肤已按当前样本阶段验收通过：人脸可识别，浅痘印与泛红有可感知的改善，预览和导出一致。产品希望解决游客照中约 90% 的常见人像问题，但现有样本不足以证明这个覆盖率。

## 新增、变更与移除

- 用真实游客照建立覆盖人物大小、肤色、光线、角度和多人合影的代表性样本集，逐张记录识别、肤色、瑕疵处理和细节保留结果。
- 对未达标场景记录原因，判断是否属于当前产品范围，再决定是否需要调整识别或美肤算法。
- 不改变现有单人照的人像优化入口和默认行为。

## 范围与非目标

- 重点补充侧脸、多人合影、不同肤色和逆光场景。
- 极小或严重遮挡的人脸、低分辨率皮肤细节、大面积深色或凹陷痘疤仍遵循当前 PRD 的边界。

## 验收标准

- 样本覆盖上述常见场景，并预先明确每张照片的通过标准；识别结果、美肤效果和局部副作用可从原图与导出图复核。
- 统计通过与失败的场景，明确可支持的覆盖范围；仅在样本具有代表性且达到目标时宣称约 90% 覆盖。

## 对后续计划的影响

- 无。
