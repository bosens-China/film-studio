# 图片滤镜工作台

## 目标与范围

面向 PC 浏览器，以深色工作台组织多张照片、预览和应用胶片滤镜，并比较原图、导出结果。图片在本地处理，不需要账号或服务器上传。手机和平板适配暂不属于首版范围。

## 图片与分组

- 导入多张照片后显示缩略图；支持拖拽导入。
- 用户可创建和命名分组，将勾选照片移动到分组，并按分组或未分组查看。删除分组不会删除照片。
- 点击照片始终进入独立详情路由，复选框用于批量操作；当前查看和批量选择彼此独立。浏览器前进和后退保留当前会话的照片和选择。
- 从分组进入详情后，在底部切换照片仍保留原分组；返回列表回到该分组。
- 右键照片可查看、选择、移动到分组或导出该照片；右键分组可查看或删除分组。菜单支持键盘访问。

## 滤镜与预览

- 首页在勾选照片后显示滤镜与调整面板，取消全部勾选后隐藏；详情页显示当前照片的滤镜面板。
- 滤镜预览正在生成时，对应图片显示处理状态；完成后展示新效果。
- 多图网格显示各照片的滤镜效果和名称。滤镜可按原有类别与人像、风景、通用场景组合筛选，并按中文名称或原名搜索。场景是保守的精选推荐，未标注的滤镜仍可在全部场景中访问。
- 用户调整滤镜和强度时先预览，明确应用后才覆盖目标照片已有设置。图库选中照片可批量预览与应用，未预览时面板参数取首张已选照片的已应用效果；批量应用按钮显示目标数量。
- 详情默认单图检视，并可切换左右对比（左边原图，右边效果）或 2 × 2 网格。每张卡片的独立缩放控件在悬停或键盘聚焦时显示。
- 详情页 header 的整体缩放同时作用于全部卡片；每张卡片也可通过自己的缩放条和拖动单独调整。整体倍率与卡片倍率叠加，调整整体倍率保留卡片已有的位置和独立缩放。
- 卡片上的复位只重置该卡片；header 的复位重置整体缩放及所有卡片的位置和缩放。切换照片后重置视图。
- 2 × 2 网格展示同一张照片的原图和三个可选择的滤镜；点击某个效果可将其选为当前预览，调整强度时使用当前聚焦槽位的滤镜。
- 放大弹窗打开后焦点进入弹窗，Tab 和 Shift+Tab 在弹窗内循环；滤镜菜单打开时 Escape 先关闭菜单，再次按下关闭弹窗。退出后焦点回到打开弹窗的按钮。
- 切换照片不会改变其他照片的设置；预览滤镜只有在明确应用时才写入照片设置。进入单张详情后试色不改变已有的批量预览。

## 导出与会话

- 首页导出勾选照片的已应用效果；详情页默认导出当前选中的视图，包括未应用的预览、原图视图或滤镜效果。导出使用原始分辨率；JPEG、PNG 和 WebP 保留对应格式，其他输入格式转换为 PNG。导出多张照片时打包为 ZIP，不覆盖原始文件。
- 四宫格可另行导出全部滤镜 ZIP：只包含三个效果槽位中已选择滤镜的结果，不包含原图；每个结果使用当前滤镜强度，并按槽位区分文件名。重复滤镜保留为独立结果，没有滤镜时禁用该入口。浏览器不支持目标格式时提示错误。
- 照片和编辑状态仅保存在当前页面会话中，刷新后不会恢复。修改或预览照片后，刷新或关闭页面触发浏览器提供的离开确认。
- 处理和导出显示进度和错误；图片逐张处理。设备支持的最大图片尺寸受浏览器和 GPU 限制。

## 素材与限制

- 项目包含整理的 293 个 Hald CLUT。其原始作者和授权尚未逐一确认，公开分发或商业使用前需要核实。
- 浏览器控制离开确认的文案和触发行为。详情地址依赖当前会话，刷新后无法恢复照片，失效时提供返回列表入口。
- 不包含云端存储、跨刷新恢复，以及颗粒、暗角、日期等 LUT 之外的效果。
