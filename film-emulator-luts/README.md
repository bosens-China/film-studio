# Film Emulator LUT 素材

来源：[Film Emulator](https://film-emulator.netlify.app/#/cn)，整理于 2026-11-12。目录按网站提供的分类和名称排列。每张 PNG 是 Hald CLUT 颜色查找表，可用于支持 Hald CLUT 的软件，或转换为其他 LUT 格式使用。

`manifest.csv` 包含原始名称、分类、本地路径、图像尺寸、每通道 LUT 级数、来源地址和 SHA-256。网站原始资源为加密的二进制文件，此处按网站前端的处理方式转换为 PNG；PNG 不包含网站另外叠加的颗粒、暗角等调整。

本目录仅整理网站公开加载的文件；每个 LUT 的原始作者、授权及商业使用权限尚未核实。使用、分发前请核实对应素材的权利与许可。
