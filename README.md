# 拾光滤镜

浏览器端照片滤镜工作台，支持批量导入、胶片 LUT、人像优化和图片导出。照片在本地处理，刷新页面后编辑状态不会保留。

[在线体验](https://bosens-china.github.io/film-studio/)

## 本地运行

需要 Node.js 22 和 pnpm 11.17.0。

```sh
pnpm install
pnpm dev
```
