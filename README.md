# 拾光滤镜 · 图片滤镜工作台

在浏览器中对多张照片分组、预览胶片滤镜、比较原图并批量导出。图片在本地处理；刷新页面后，照片和编辑状态不会恢复。

## 使用

需要 Node.js 和 pnpm 11.17.0。

```sh
pnpm install
pnpm dev
```

打开终端显示的本地地址（默认 `http://localhost:10107`）。添加照片后可创建分组、勾选照片，并通过场景和类别筛选滤镜。试用时先预览，点击应用后才更新照片；点击照片始终进入独立详情页，默认单图检视，可切换左右或 2 × 2 对比。右键照片或分组可以打开操作菜单；键盘聚焦后也可按 Shift+F10。首页导出所选照片已应用的效果；详情页默认导出当前选中的视图，包括未应用的预览。四宫格还可将三个效果槽位中已选择的滤镜分别导出为 ZIP（不含原图，重复滤镜按槽位分别保存）。JPEG、PNG 和 WebP 保留对应格式，其他输入格式转换为 PNG。

详情页的「整体缩放」控制全部卡片；卡片悬停或键盘聚焦时右上角可单独缩放和复位，拖动图片可调整该卡片的位置。整体缩放保留卡片的单独调整，header 的复位则重置全部视图。

```sh
pnpm lint
pnpm build
pnpm exec playwright install chromium
pnpm test
```

照片、分组和选择等共享会话状态集中在 `src/stores/workspace.ts`；局部交互使用 React 和 ahooks。状态只保存在内存中，刷新后不会恢复。

浏览器须支持 WebGL 2；原图处理上限取决于设备。导出按原始分辨率生成图片，超出设备限制时会显示错误；一次导出大量照片可能需要较多内存。JPEG 会重新编码，原文件中的 EXIF 等元数据可能不会保留。

产品行为见 [PRD](docs/PRD.md)。仓库中的 LUT 和示例图片来源及许可尚未逐一核实，公开分发或商业使用前需确认使用权限。
