# 拾光滤镜 · 图片滤镜工作台

在浏览器中对多张照片分组、预览胶片滤镜、比较原图并批量导出。图片在本地处理；刷新页面后，照片和编辑状态不会恢复。

在线体验：[GitHub Pages](https://bosens-china.github.io/film-studio/)。推送到 `main` 后，GitHub Actions 会运行 lint、构建并部署。

## 使用

需要 Node.js 和 pnpm 11.17.0。

```sh
pnpm install
pnpm dev
```

打开终端显示的本地地址（默认 `http://localhost:10107`）。添加照片后可创建分组、勾选照片，并通过场景和类别筛选滤镜（查看全部类别时按类别分段显示；“无滤镜”表示不套用滤镜，与人像优化相互独立，原图始终不被修改）。选择滤镜、调整强度或切换人像优化会立即作用于照片，可用 ⌘Z / Ctrl+Z 撤销、⇧⌘Z / Ctrl+Y 重做；点击照片始终进入独立详情页，先以单图查看；一旦修改效果会自动切到左右对比，左边原图保持不变作为参照，也可切换 2 × 2 网格，按住 `\` 查看原图，←/→ 切换照片。检测到人脸的照片默认开启人像优化（逆光提亮人物、保边柔肤、肤色去红并减弱滤镜对肤色的影响），可在右侧面板单独关闭，或在右上角设置中关闭自动开启。页头的两个面板开关或 `[` / `]` 可显示或隐藏分组栏和滤镜栏，详情页默认收起分组栏。右键照片或分组可以打开操作菜单；键盘聚焦后也可按 Shift+F10。首页导出所选照片的效果；详情页导出当前照片的已应用效果（详情页不提供添加照片，需返回图库添加）。四宫格还可通过导出按钮旁的下拉菜单将三个效果槽位中已选择的滤镜分别导出为 ZIP（不含原图，重复滤镜按槽位分别保存）。JPEG、PNG 和 WebP 保留对应格式，其他输入格式转换为 PNG。

鼠标停在任意卡片上即可滚轮缩放（以指针为中心，触控板双指捏合同样有效），按住直接拖动平移，无需先点选卡片。左右对比和 2 × 2 网格默认「联动」，缩放和拖动同步到所有卡片，便于对照同一处细节；关闭联动后各卡片独立。卡片悬停或键盘聚焦时右上角提供缩放条和单卡复位，工具栏的「复位」重置全部视图。

```sh
pnpm lint
pnpm build
pnpm exec playwright install chromium
pnpm test
```

照片、分组和选择等共享会话状态集中在 `src/stores/workspace.ts`；局部交互使用 React 和 ahooks。状态只保存在内存中，刷新后不会恢复。

浏览器须支持 WebGL 2；原图处理上限取决于设备。导出按原始分辨率生成图片，超出设备限制时会显示错误；一次导出大量照片可能需要较多内存。JPEG 会重新编码，原文件中的 EXIF 等元数据可能不会保留。

产品行为见 [PRD](docs/PRD.md)。仓库中的 LUT 和示例图片来源及许可尚未逐一核实，公开分发或商业使用前需确认使用权限。
